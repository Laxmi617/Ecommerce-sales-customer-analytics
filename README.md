# Ecommerce-sales-customer-analytics
# Business Problem
Olist (Brazilian E-Commerce) CEO wants to grow revenue by 15% in Q4. The goal is to identify which customer segments, regions, and product categories to focus on for maximum revenue growth.

# Key Insights
Top 5% customers contribute 23% of total revenue
São Paulo = 37% of all revenue (7.7M BRL)
Bed & Bath Table = highest revenue category (1.74M BRL)
28.9K customers are At-Risk — need immediate retention strategy
69.59% payments via Credit Card

# Tools Used
Python -> Data Cleaning, EDA, RFM Segmentation | MySQL -> Business Queries, Data Analysis | Power BI -> Interactive Dashboard | Pandas -> Data Manipulation
